## Owner decision
- **Bubka's English name**: drafted as "Sergey Bubka" (World Athletics, Britannica). The IOC uses "Sergii"; official transliteration is "Serhii".
- **Wladimir's birthplace**: ESU says "Solnechnyi, now Zhangiz-Tobe". But ru.wiki says Solnechnyi (the missile-division garrison) was renamed **Shuak** in 2011. It is a separate village about 3 km from Zhangiztobe (49.205, 81.178). It is now in Abai Region, not East Kazakhstan. Options: (a) keep the ESU wording (as now); (b) write "Solnechnyi (now Shuak, near Zhangiztobe)" with Shuak's coordinates. That would rest on Wikipedia alone. The map is not affected (abroad, KZ).
